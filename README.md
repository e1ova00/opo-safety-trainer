# Тренажёр «Допуск»

Учебная демонстрация (курсовая работа): игровой тренажёр для обучения персонала вопросам
промышленной безопасности и охраны труда на опасных производственных объектах нефтегазодобычи.

- 10 уровней: от «Стажёра» до «Допущен к работам повышенной опасности».
- Перед каждым уровнем — короткая теория со схемами.
- Тестовые вопросы (≈75 %) и ситуационные задания (≈25 %), в том числе «расставьте действия по порядку».
- Баллы за верные ответы, штраф и потеря «здоровья на ОПО» за ошибки.
- Вопросы зависят от должности: оператор по добыче нефти и газа, инженер по ПБ, электрогазосварщик.
- Личный кабинет, рейтинг (с вымышленными работниками), 10 бейджей, поздравления, фоновая музыка.
- После финала — запись для наряда-допуска с QR-кодом.
- Раздел специалиста по ПБ: все вопросы с правильными ответами, редактирование вопросов и теории,
  пороги баллов, записи, описание концепции. **Пароль: `1234`.**

Данные сохраняются только в браузере того устройства, на котором открыт тренажёр (localStorage).
Синхронизации между устройствами нет — так задумано для демонстрации.

## Как запустить на компьютере с Windows

1. На странице репозитория нажмите зелёную кнопку **Code** → **Download ZIP**.
2. Распакуйте архив (правый клик → «Извлечь всё»).
3. Откройте папку и дважды щёлкните файл `index.html` — он откроется в браузере (Edge или Chrome).

Интернет нужен только для красивых шрифтов; без него всё работает со стандартными шрифтами.

## Как открыть на телефоне и планшете

Включите бесплатный хостинг GitHub Pages:

1. В репозитории откройте **Settings** → слева **Pages**.
2. В блоке **Build and deployment** выберите **Source: Deploy from a branch**,
   ветку **main** и папку **/ (root)**, нажмите **Save**.
3. Через 1–2 минуты сверху появится адрес вида `https://e1ova00.github.io/opo-safety-trainer/`.
   Откройте его на телефоне или планшете. Результаты на каждом устройстве сохраняются отдельно.

## Структура

| Файл | Что внутри |
|---|---|
| `index.html` | Разметка и стили (адаптивно: телефон, планшет, компьютер) |
| `js/data.js` | Контент: уровни, теория, вопросы, бейджи, схемы, вымышленный рейтинг |
| `js/app.js` | Логика: прохождение уровней, баллы, здоровье, бейджи, кабинет, QR, админ-раздел |
| `js/vendor/qrcode.js` | Библиотека генерации QR-кодов (Kazuhiko Arase, лицензия MIT) |
| `docs/CONCEPT.md` | Концепция для пояснительной записки |

Вопросы составлены по общим требованиям 116-ФЗ, Трудового кодекса и правил безопасности
в нефтегазовой отрасли в учебных целях. Перед реальным использованием их должен проверить специалист по ПБ.
