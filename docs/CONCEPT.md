# Концепция тренажёра «Допуск»

Игровой тренажёр (serious game) для обучения и проверки знаний по промышленной безопасности
и охране труда работников нефтегазодобывающих ОПО, которым нужен наряд-допуск.

## Порядок работы

1. Работник регистрируется: ФИО, табельный номер, подразделение, должность, вид проверки знаний.
2. Перед каждым уровнем изучает короткую теорию (карточки со схемами).
3. Проходит 10 уровней подряд. На уровне — тесты и ситуационные задания (≈75 % / 25 %).
4. За верный ответ получает баллы, за ошибку теряет баллы и «здоровье на ОПО».
5. Набрал порог — переходит на следующий уровень. После финального 10-го уровня система формирует запись.
6. По записи строится QR-код, который используют при оформлении наряда-допуска.
7. Результаты хранятся в личном кабинете, ведётся рейтинг, выдаются бейджи.

## 1. Уровни и пороги

Каждый уровень: 6 тестовых вопросов (по 10 баллов) + 2 ситуационных задания (по 20 баллов) = 100 баллов.
Финал: 9 тестовых + 3 ситуационных = 150 баллов. Пороги меняет специалист по ПБ.

| № | Уровень | Тема | Порог / максимум |
|---|---|---|---|
| 1 | Стажёр | Общие требования ПБ | 60 / 100 |
| 2 | Ученик | Охрана труда | 60 / 100 |
| 3 | Младший специалист ОПО | Средства индивидуальной защиты | 65 / 100 |
| 4 | Специалист ОПО | Пожарная безопасность | 70 / 100 |
| 5 | Опытный специалист | Первая помощь | 70 / 100 |
| 6 | Ответственный исполнитель | Наряд-допуск | 75 / 100 |
| 7 | Старший специалист | Действия при аварии | 75 / 100 |
| 8 | Профессионал участка | Профиль должности | 80 / 100 |
| 9 | Кандидат на допуск | Все темы | 80 / 100 |
| 10 | Допущен к работам повышенной опасности | Финальный экзамен: все темы + профиль | 130 / 150 |

Максимум за всё обучение — 1050 баллов. В рейтинг идёт лучший результат по каждому пройденному уровню.

## 2. Здоровье на ОПО

- На каждую попытку уровня — 3 единицы здоровья (сердечки).
- Ошибка: −5 баллов (не ниже нуля) и −1 здоровье.
- 3 верных ответа подряд восстанавливают 1 здоровье (не больше максимума).
- Здоровье закончилось — попытка прекращается и не засчитывается. Уровень можно пройти заново, повторив теорию.
- Ограничения по времени на ответ нет.

## 3. Бейджи

| Бейдж | Условие |
|---|---|
| Бейдж Профессионала | Достичь 5-го уровня |
| Знатоки Безопасности | 10 верных ответов подряд |
| Мастера Контроля | Пройти уровень 6 «Наряд-допуск» без ошибок |
| Безопасные Титаны | Набрать 900 баллов в сумме |
| Операторы Превосходства | Войти в тройку лидеров рейтинга |
| Стражи Порядка | Верно решить 10 ситуационных заданий |
| Инспекторы Доверия | Пройти 3 уровня подряд с первой попытки |
| Бейджи Экспертов | Сдать финальный 10-й уровень |
| Лидеры Безопасности | Занять 1-е место в рейтинге |
| Защитники Стандартов | Пройти 3 любых уровня без единой ошибки |

## 4. Личный кабинет

- Профиль: ФИО, табельный номер, должность и уровень её опасности, подразделение, вид проверки.
- Показатели: текущий уровень, баллы, место в рейтинге, точность ответов.
- Запись для наряда-допуска: QR-код, номер, срок действия, статус.
- Бейджи: полученные (с датой) и условия получения остальных.
- История всех попыток: дата, уровень, баллы, верные ответы и ошибки, итог.

## 5. Содержание и адаптация под должность

Темы: общие требования ПБ, охрана труда, СИЗ, пожарная безопасность, первая помощь, наряд-допуск,
действия при аварии. В банке 123 задания (около 25 % — ситуационные). Часть вопросов общая для всех,
часть — только для конкретной должности. Уровень 8 целиком посвящён профилю должности,
в финале обязательно есть вопросы профиля.

| Должность | Опасность | Профиль |
|---|---|---|
| Электрогазосварщик | очень высокая | огневые работы, газовые баллоны, сварочное оборудование |
| Оператор по добыче нефти и газа | высокая | станки-качалки, устье скважины, сероводород, газоопасные работы |
| Инженер по ПБ | средняя (контрольные функции) | производственный контроль, наряды-допуски, расследования |

Примеры теории, тестов и ситуационных заданий — в приложении (раздел специалиста → «Вопросы и ответы»)
и в файле `js/data.js`.

**Пример теста.** Каким огнетушителем можно тушить электрооборудование под напряжением до 10 кВ?
Углекислотным (ОУ) ✓ / водным / пенным / воздушно-пенным.

**Пример ситуации.** Мастер просит срочно заменить прокладку на фланце, давление не сброшено.
Правильно: отказаться работать под давлением, потребовать отключить участок и сбросить давление, сообщить о нарушении.

**Пример задания на порядок.** Газоанализатор подал сигнал по сероводороду: надеть противогаз →
выйти поперёк ветра, затем в наветренную сторону → сообщить диспетчеру → действовать по ПМЛА.

## 6. Запись для наряда-допуска и QR-код

1. Работник сдаёт финальный 10-й уровень.
2. Система формирует запись: номер (ПБ-ГГГГ-XXXXXX), ФИО, табельный номер, должность, подразделение,
   уровень, баллы, дату, вид проверки, срок действия, контрольный код.
3. Из текста записи строится QR-код. Работник показывает его лицу, выдающему наряд-допуск.
4. Срок действия:
   - общая проверка знаний требований НПА — по нормам (в тренажёре по умолчанию 12 месяцев, настраивается);
   - подготовка к работам повышенной опасности — до начала работ и выдачи следующего наряда-допуска.
     Специалист отмечает выдачу наряда кнопкой «Наряд-допуск выдан», запись закрывается.
5. Специалист может проверить запись по номеру или контрольному коду.

## 7. Визуальный стиль и тон

Строгий промышленный стиль с дружелюбным и мотивирующим тоном. Нефтяной сине-зелёный основной цвет,
сигнальный оранжевый для действий, «сигнальная» полоса как фирменный элемент. Простые схемы оборудования
(станок-качалка, фонтанная арматура, огнетушитель, газоанализатор, баллоны). Ошибки объясняются спокойно,
без упрёков. Нейтральная фоновая музыка, конфетти и поздравление при новом уровне и бейдже. Есть тёмная тема.
